## 验证边界

本环境无法访问原生 Windows / Linux 安装界面，审查浏览器也无法打开本地预览，因此没有声称本轮已取得有效截图、通过安装版视觉审计或完成真实 Paddle 模型下载/识别测试。本轮前端交互回归使用模拟原生桥；实际 PDF 测试使用真实 PDFium，但扫描页预测器使用测试替身。

不宣称消除了所有长文档开销：第一次整理千页文档仍需处理全部文字；全文输出本身也随文档变长。当前优化针对基准明确测到的深度监听与重复投影，不引入没有证据支持的大规模重构。

## 三平台安装版重点验收

1. 1080p 下 100%/125%/150% 缩放的初始页；确认主操作可达，设置展开且下拉字号一致。添加较多任务或展开维护后，列表/侧栏允许有意滚动。
2. 输入有效/非法/空页码后直接点开始；确认没有旧范围误识别，切换文件后范围保持。
3. 慢页处理中暂停，待确认后继续；在最后一页附近暂停、跳过、取消和强停；任务状态与后台一致。
4. 普通模型准备过程中停止，再重新准备；离线缺模型场景给出可操作信息。
5. 无模型打开纯文本 PDF；混合 PDF 提取前几页后下载模型继续，断网时已完成页仍可导出。
6. 在双栏右边校对早期页，后续页面到达不跳位、不覆盖编辑；重启后恢复相同文本。
7. 100 行、20 列长表在顶部/中部/底部及跨多表时，横向条始终可见、不遮挡、不出现双条。
8. 三种导出范围 × 两种文字版本 × TXT/XLSX/HTML；确认排除图片不混入合并表，原始查看不改变导出。
9. 专注 Ruby 开关及两栏复制；剪贴板拒绝、自动保存失败仍有可见反馈。

## 构建

将源码包解压后，把项目根目录的内容上传到 GitHub，保留 `.github/workflows/build-desktop.yml`。手动运行 Build Windows and Linux x64，或按原规则推送版本标签。产物仍是 Windows NSIS 安装包、普通 Linux AppImage、WebKitGTK 4.0 / glibc 2.28 兼容 AppImage。

本地合成基准可运行：`node --expose-gc scripts/benchmark-text.mjs docs/PERFORMANCE-0.13.0.json`。记录不含真实文档内容。
