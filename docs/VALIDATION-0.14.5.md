# 0.14.5 验证记录

跨页正文与跨页表格选项集中到文档设置。正文原有逻辑仍要求完整任务、连续页码、版面信息及可连接段落；表格仍要求每页一张、列数一致和重复表头。此次不加入强制合并。

修复 partial 表格结果直接返回缓存、忽略开关的问题。完整任务继续复用完成时生成的合并结果，避免长表反复计算。表格未合并时列出页码及原因；正文说明完成条件与连接数。

120 页测试发现相似数据行的不同数字可能被模糊表头匹配误删，现增加数字一致性要求。已有历史保存逐页数据，恢复时会按当前算法重新生成合并结果。

验证：123 项前端测试、11 项配置测试；普通与 WebKitGTK 4.0 前端构建。覆盖 120 页合并、拆分、数据行保留和未合并原因；现有正文开关、非连续页面和未完成任务边界测试通过。

没有用户的原始 PDF 或识别数据，无法确定其表格具体不满足哪个合并条件。未在本地编译原生包或运行真实 OCR；目标系统需使用 Actions 构建后验证。
