# 0.10.0 文本处理说明

## 默认设置与作用时机

文档预览上方的折叠面板不会增加左侧栏高度。

| 设置 | 默认 | 修改后何时生效 |
| --- | --- | --- |
| PDF 文字来源 | 自动 | 下次识别；变更后不复用旧断点 |
| 日语注音识别 | 关闭 | 下次识别；变更后不复用旧断点 |
| 文本整理 | 智能 | 立即从原始页结果重新生成 |
| 跨页正文 | 开启 | 完整任务且物理页连续时 |
| 注音输出 | 括号 | 立即使用已保存的注音数据 |

识别过程中暂时禁止更改整理选项，避免阅读内容突然重排；完整任务结束后执行文档级整理。手工校对版优先，不会被自动覆盖。“恢复自动整理版”会经确认放弃手工文字，但不改变原始识别数据。

## PDF 取文

继续使用已有 PDFium。自动分支读取 Unicode、字号、字框，将 PDF 的左下坐标转换为左上坐标并分组。仅可靠文本页跳过渲染与 OCR。扫描图像、明显乱码、旋转或非标准裁剪坐标回退整页 OCR；页面存在较大图片时也保守回退，以免只提取标题而遗漏图片内正文。表格模式始终使用原有视觉流水线。

这是启发式检查，不是文本层完整性证明。尤其是错误但仍为合法汉字的 OCR 覆盖层、轮廓化文字和特殊编码，仍应检查输出，必要时选择强制 OCR。自动取文不是绕过 PDF 权限的功能，不提供密码破解。

当前队列仍在开始时准备所选模型；即使最终全部直接取文，也有一次模型准备开销。文字直接提取不受最低 OCR 置信度筛选，分数为 null 而非伪造 100% 置信度。

## 日语注音（实验性）

目标是背景干净、字号规则的现代书籍。每页按主要排版方向检测横排上方或竖排右侧的小字。PDF 文本层优先以字符中心与注音覆盖范围绑定；扫描页通过连通域/字号分组分离小字，局部放大后识别，再按文字框估算字词范围。

PDF 注音开启时，扫描回退页最高按约 300 DPI 渲染，同时受 2400 万像素和单边 8192 上限保护。不修改用户源文件，不上传页面。暂停与取消也在局部注音块之间检查；注音尚未处理完的页面不写为完成检查点。

可选择正文、括号、HTML Ruby。复制和 TXT 无法表达小字排版，因此 Ruby 模式复制为括号。HTML 预览使用转义后的有限标签；导出再执行允许列表过滤。未绑定的小字留在原始结果，正文不强行插入；无法检测/识别的小字仍可能遗漏。扫描页绑定是估算，应校对。原始结果是识别到的原始文字块，不等同于保证完整的原页转录。

不要把提高置信度当作删除注音：正文也会被筛掉。不会用词典生成图中不存在的读音。特殊义训可保留识别到的内容，但漫画、古籍双行夹注、双侧 Ruby、复杂横竖混排不在本次承诺范围。

## 文本整理与性能

原始数据只识别和保存一次。前端对每页、每种输出设置缓存阅读顺序和行整理，不再次访问源文档；完整任务再做一次文档级页边重复文本过滤与跨页连接。整份纯文本的显示/复制/导出仍需拼接字符，因此内存和输出时间会随全文长度增长，并非恒定开销。

智能模式依据字号、坐标间距、缩进、列表/对话开头和短行判断段落。中日文衔接不加空格，拉丁文字衔接补空格。软连字符自动移除；普通行末连字符只在同一文档出现完整拼写时尝试移除，不会一律删掉 well-known 等复合词。语言与段落判断可能有误，可切原始结果或手工修订。连续模式保留明确的列表/对话边界，减少其他段落判断。

跨页连接不会跨过未选择的物理页面，不连接仍在运行、已取消或未完整恢复的任务。页眉页脚仅在页面边缘且重复至少 3 页并覆盖大多数页面时移除；孤立页码仅在页边判定，不删除正文数字。不同页的句末标点可能导致保守保留分段。

旧结果缺少新字段时不猜测坐标；仍能查看、复制、导出及保留校对。首次要补提取注音必须重识别，只有注音格式切换不需要。

## 验证范围

新增单元测试覆盖真实 PDF 文本提取/渲染跳过、扫描回退、图片正文页、非法 Unicode、混合页面、续识及中途取消、横竖注音几何、OCR 小字候选、多语言断行、旧记录/手工文字保护、HTML 注入防护和前端切换/复制。

Actions 的既有模型迁移冒烟增加冻结 sidecar 的文本层、混合页与注音开启分支；这只验证流程，不证明日语书籍的准确率。请用几份实际横排/竖排书页验证识别和汉字绑定，再用于长书。
